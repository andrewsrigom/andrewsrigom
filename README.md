## About

I’m a Senior Full-Stack Software Engineer with 10+ years of experience building production systems across fintech, e-commerce, and SaaS.

Today I’m focused on AI engineering, backend architecture, and developer tooling: retrieval systems, agent runtimes, APIs, data pipelines, and reliable execution. I work end to end, from system boundaries and data models to the interfaces people use.

## Current focus

- **Agentic systems** — retrieval, MCP integrations, multi-agent workflows, provider-neutral model routing, tool execution, and human approvals.
- **Backend infrastructure** — queues, scheduling, resumable execution, concurrency, cancellation, failure recovery, and observability.
- **Developer tooling** — isolated execution, typed output contracts, immutable artifacts, static analysis, CI policy gates, and traceable results.

## Selected work

### [VaultMind](https://github.com/andrewsrigom/vaultmind)

Self-hosted knowledge system that turns GitHub, Notion, Google Drive, and local documents into searchable answers with source-level citations.

`TypeScript` · `PostgreSQL` · `pgvector` · `RAG` · `MCP`

### [Aster](https://github.com/andrewsrigom/aster-streaming-platform)

End-to-end VOD platform for openly licensed films, built around federated GraphQL services, explicit data ownership, resilient playback, and observable failure recovery.

`TypeScript` · `Node.js` · `GraphQL Federation` · `PostgreSQL` · `Docker`

### [CodebaseScan](https://github.com/andrewsrigom/codebasescan)

Local-first auditing that finds security, reliability, and maintainability risks in Node.js, React, and Next.js codebases — without executing the target project.

`TypeScript` · `Node.js` · `Static Analysis` · `SARIF` · `CI/CD`

### [Caderno UI](https://github.com/andrewsrigom/caderno-ui)

Notebook-inspired component library that runs across frameworks through Web Components, with dedicated React and Astro adapters.

`TypeScript` · `Web Components` · `Lit` · `Design Systems`
